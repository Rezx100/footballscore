# Scoreva — Higgsfield generation prompts

Production-ready prompts for the Scoreva visual identity. Lock hex, type, and copy exactly as written — these are not exploratory prompts.

Brand constants referenced below:
- Palette (Aperture): night `#08090D` · studio `#111318` · plate `#181B22` · hairline `#2A313C` · bone `#F3F0E8` · mute `#8B93A1` · volt `#D7FF3C` · ember `#FF5A2D` · cardRed `#E23D3D` · cardAmber `#E6B84A` · ice `#6EC8E0`.
- Type: Outfit (wordmark/titles), Inter (body), IBM Plex Mono tabular (scores/minutes/kick-off).
- Hero fixture for UI mocks: **Arsenal vs Chelsea, 2–1, 67'**, generic geometric monogram crests (angular heraldic shields, NOT the real club badges), no real kit, no real player likenesses.
- Never: a football/soccer ball as the mark, pitch-green backgrounds, purple chrome, red full-bleed goal cards, FotMob grey groups, Apple Sports green, betting/odds/Watch CTAs.
